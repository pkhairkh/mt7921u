# Patches

One file per patch, numbered in application order, applied on top of the
upstream mt76 tree. The result is committed under
`drivers/net/wireless/mediatek/mt76/`. Summaries live in
`docs/patch-series.md`; the patch files themselves carry the detailed
rationale.

Numbering is not contiguous: 0015/0016 were commit-level reworks and
0024-0026 were applied directly to the working tree, so no files exist
for those numbers.
